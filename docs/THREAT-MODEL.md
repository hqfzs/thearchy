# 威胁模型

## 不可信输入

- 仓库文件与注释；
- Issue、PR 和任务描述；
- 下载的模板；
- 测试、构建和工具输出；
- Agent 生成的工单与报告。

## 主要威胁

1. 提示词注入诱导 Agent 跳过质量门。
2. 路径穿越或符号链接读取秘密。
3. 远程模板携带可执行代码。
4. 多 Agent 同时修改相同工作区。
5. 审查 Agent 接触实现者隐藏上下文后失去独立性。
6. 伪造测试结果或把缺少测试标记为通过。

## 缓解

- 本地状态机验证每次转换。
- 固定角色 ID 和允许状态。
- 路径边界、秘密路径拒绝和远程扩展名白名单。
- worktree 隔离和用户合并审批。
- 审计日志记录角色、产物哈希和审批。
- 无验证证据时输出 `unverified`。
