# 支持范围

## 首个正式版本

神治首个正式版本的支持矩阵限定为：

- 操作系统：Windows；
- 宿主：Codex Desktop；
- 安装方式：个人 marketplace 一键安装；
- 运行方式：插件内嵌本地协调器。

以下实现继续保留，但在首个正式版本中标记为实验性，不作为发布阻断条件：

- macOS；
- Linux；
- Claude Code 适配器。

## 稳定版发布门槛

1. Windows 上安装、升级、卸载和状态检测全部通过。
2. Codex Desktop 正确声明子 Agent、并行 Agent 和 MCP 能力。
3. 低风险自动轻量、中风险询问、高风险强制完整的分流测试通过。
4. 轻量模式始终不超过2个子 Agent，并保留独立验证。
5. 优化后基准无状态损坏、无重复运行、无高严重度安全问题。
6. npm tarball 可安装并执行。

跨平台 CI 继续运行，用于防止代码退化，但其失败不会扩大首个正式版本的支持承诺。
